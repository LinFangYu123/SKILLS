# 通用审查清单（兜底）

适用于无对应语言清单的文件（shell、配置、Lua、SQL脚本等），
以及任何语言清单之外仍需覆盖的通用维度。逐类过检。

## 1. 缺陷类（🔴）

- **边界条件**：空输入、单元素、最大值；索引从 0 还是从 1；区间开闭
- **错误处理**：失败路径被忽略或吞掉；部分失败后的状态是否一致
- **资源管理**：文件/连接/进程句柄在所有路径（含出错路径）上释放
- **时序假设**：依赖"先 A 后 B"的隐式顺序无显式保证（竞态、重试后行为）
- **幂等性**：可重入/可重试的操作重复执行会不会出错（重复扣款、重复建目录）
- **编码与转义**：特殊字符（空格、引号、换行、`$`、`%`）未经转义进入命令/路径/查询

## 2. 安全类（🔴）

- 外部输入未经校验直接用于：命令执行、路径拼接、查询、HTML/模板渲染
- 明文密钥/口令/Token 入代码或日志
- 权限检查缺失：操作前未验证调用者是否有权访问目标资源
- 过时/已知漏洞的依赖版本或算法（MD5/SHA1/DES）

## 3. 隐患类（🟡）

- **死代码**：定义但无调用的函数、不可达分支、被注释掉的代码块
- **重复**：三处以上相同逻辑未提取；拷贝粘贴后只改了一半的痕迹
- **复杂度**：单函数/脚本 >100 行且多职责；嵌套 >3 层
- **魔法值**：散落的状态码/阈值/路径字面量无命名
- **配置与代码耦合**：环境差异（路径、URL、开关）硬编码

## 4. 风格类（🔵）

- 命名一致、见名知义；与项目既有风格校准（读相邻文件），不强推个人偏好
- 注释解释 WHY 而非 WHAT；无过时注释
- 无调试残留（打印语句、TODO-FIXME 无跟踪号）
