# C / C++ 审查清单

逐类过检，每类都给出结论（有问题列出，无问题跳过）。
本清单以内存安全与未定义行为为核心（Trail of Bits 实践提炼）。

## 1. 内存安全（🔴，C/C++ 通用）

- **分配/释放配对**：每个 `malloc`/`new` 路径都有对应 `free`/`delete`，含提前 return / 错误分支；`new[]` 配 `delete[]`
- **use-after-free / double-free**：释放后指针未置 NULL 且仍被访问；同一指针两条路径释放
- **内存泄漏**：错误提前返回路径跳过释放；C++ 裸 new 无智能指针托管
- **悬垂引用**：返回局部变量地址/引用；容器扩容/erase 后继续使用迭代器与指针
- **C++ RAII**：应使用 `unique_ptr`/`shared_ptr`/容器代替手动管理；`shared_ptr` 循环引用未用 `weak_ptr`

## 2. 缓冲区与越界（🔴）

- **数组边界**：`memcpy`/`strcpy`/`sprintf`/`gets` 等无界操作；目标缓冲区大小来自不可信输入
- **off-by-one**：`<=` 边界、`n-1` 与 `n` 混淆、循环终止条件
- **`sizeof` 误用**：对指针取 sizeof 得 8 而非数组大小；`sizeof(buf)/sizeof(buf[0])` 用在退化成指针的参数上
- **字符串未终止**：`strncpy` 不保证 NUL 结尾；手动构造的缓冲区漏 `\0`

## 3. 未定义行为（🔴）

- **整数溢出**：无符号回绕（长度计算 `a+b` 溢出）、有符号溢出（UB）；乘法/加法前未检查，或未用 checked 满加
- **窄化截断**：`size_t` → `int`、`long` → `int` 隐式截断后用于长度/索引
- **移位**：移位位数 ≥ 类型宽度；负数左移；`1 << 31` 用在 int 上（应 `1u`）
- **未初始化**：局部变量/结构体字段使用前未初始化；`malloc` 后未 memset 且当整块读
- **别名与对齐**：违反严格别名（`*(int*)&float_var`）；未对齐指针访问
- **序列点**：`i++ + ++i` 类未定义求值顺序

## 4. 输入与错误处理（🔴/🟡）

- **返回值未检查**：`malloc`/`read`/`write`/`fopen` 等可失败的调用未检查返回
- **format string**：`printf(user_input)` 而非 `printf("%s", user_input)` → 格式字符串攻击
- **TOCTOU**：先 `access`/`stat` 再 `open` 的检查与使用间隙
- **外部输入信任边界**：网络/文件/环境变量进来的长度、索引、数量字段未做上界校验

## 5. C++ 专项（🟡）

- **Rule of 0/3/5**：自定义析构/拷贝/移动不完整；应删除拷贝的没删除
- **异常安全**：new 后多步初始化中抛异常泄漏；析构函数抛异常
- **const 正确性**：不该改的成员函数/参数/返回值缺 const
- **隐式转换**：单参构造函数未 `explicit` 导致意外转换

## 6. 并发（🔴/🟡）

- 无锁保护共享数据；`pthread_mutex_*` 错误分支未解锁
- `volatile` 被误当线程同步原语（它不是）
- 信号处理函数中调用非 async-signal-safe 函数

## 7. 风格类（🔵）

- 资源获取与释放就近；函数单一职责；魔数用命名常量/enum
- C++ 优先 `std::vector`/`std::string` 而非裸数组/字符指针
- 注释解释 WHY；头文件有 include guard / `#pragma once`
