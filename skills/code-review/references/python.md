# Python 审查清单

逐类过检，每类都给出结论（有问题列出，无问题跳过）。

## 1. 缺陷类（🔴）

- **可变默认参数**：`def f(x=[])` / `def f(x={})` —— 默认值在函数定义时求值一次，跨调用共享。改用 `None` + 函数体内初始化
- **`is` 与 `==` 混用**：`is` 只用于 `None`/`True`/`False`/哨兵对象；值比较一律 `==`
- **裸 `except:` / `except Exception` 后吞异常**：必须捕获具体异常类型；确需兜底时记录日志再 raise
- **闭包晚绑定**：循环内定义 lambda/函数引用循环变量，回调时取到的是最终值。用默认参数固定 `lambda i=i: ...`
- **迭代时修改容器**：遍历 dict/list 时增删元素 → RuntimeError 或漏元素。改为遍历副本或收集后统一处理
- **资源未释放**：文件/连接/锁必须用 `with` 或 try/finally
- **异步误用**：`asyncio` 里调用阻塞函数（`time.sleep`、同步 IO）卡死事件循环；未 await 的协程静默不执行
- **可变对象作模块级状态**：多入口/多线程共享的可变全局，未加锁

## 2. 安全类（🔴）

- `eval()` / `exec()` / `pickle.loads()` 处理外部输入 → 代码执行
- SQL 拼接（f-string / `%` / `+`）→ 注入。必须参数化查询
- `subprocess` 用 `shell=True` 且命令含用户输入 → 命令注入
- `yaml.load` 未指定 `Loader=SafeLoader`
- `tempfile` 可预测路径、`os.path.join` 拼接用户输入未做路径规范化（目录穿越）
- 硬编码密钥/口令/Token

## 3. 隐患类（🟡）

- **类型注解缺失**：公共函数/方法无类型注解；注解与实际行为矛盾
- **异常粒度**：一个 try 包太大段代码，掩盖真实出错点；自定义异常全部继承 `Exception` 无层次
- **魔法数字/字符串**：无命名字面量散落（状态码、配置键）
- **函数过长/参数过多**：>50 行或 >5 参数考虑拆分；布尔参数串考虑 dataclass
- **深嵌套**：>3 层 if/for 嵌套，用卫语句提前返回展平
- **f-string 与 logging 混用**：日志用 `logger.info("x=%s", x)` 惰性格式化，不用 f-string（除非必须）

## 4. 风格类（🔵）

- 命名：模块/函数 `snake_case`，类 `PascalCase`，常量 `UPPER_SNAKE`
- 导入顺序：标准库 → 三方 → 本地，组间空行；无未使用的导入/变量
- 公共模块/类/函数有 docstring；注释解释 WHY
- 与项目现有风格一致（读 1-2 个相邻文件校准，不强推 PEP8 到已有不同惯例的代码库）
